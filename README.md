# Dank Coders - Personal Portfolio Pages

A small college assignment built with plain HTML and internal CSS. The project is a three-page portfolio site for our team, **Dank Coders**.

## Pages

| File | Description |
|---|---|
| `profile.html` | About the team, education and interests |
| `skills.html` | Tools and technologies we work with |
| `contacts.html` | Contact card with email, phone and location |

Each page links to the others through the buttons at the bottom of the card.

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/sakshamhada-tech/dank-coders-3.git
   ```
2. Open the project folder.
3. Double-click `profile.html` (or any other page) to open it in your browser.

No installation or build step is needed.
